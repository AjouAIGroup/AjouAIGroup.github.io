서비스별 선택지

AAIG처럼 정보 제공이 중심인 연구그룹 사이트에는 비용과 개인정보 부담이 작은 선택지가 유리합니다.

선택지 Cloudflare Web Analytics Google Analytics 4
월 서비스 비용 무료 권장 무료
주요 용도 방문 수, 인기 페이지, 유입 경로, 국가, 기기, 로딩 성능 방문자 행동, PDF와 외부 링크 클릭, 맞춤 이벤트
개인정보 부담 낮음. Cloudflare는 방문자 개인정보를 수집하거나 사용하지 않는다고 안내합니다. 상대적으로 높음. 쿠키와 동의 설정을 검토해야 합니다.
관리자 화면 연결 가능. GraphQL API를 서버리스 함수 뒤에 연결 가능. Data API와 서비스 계정 설정 필요
운영 복잡도 낮음 중간 링크 클릭 분석이 필요할 때

비용을 두 층으로 나누어 봅니다

서비스 비용은 작지만, 실제 관리 기능의 범위에 따라 초기 구축 작업은 달라집니다.

기본 분석만

₩0 / 월

Cloudflare 대시보드에서 통계를 직접 확인합니다.

  • 방문 통계와 성능 확인
  • 홈페이지 코드에 스니펫 1회 추가
  • 관리자 페이지 개발 없음

권장: 통합 관리자

₩0 / 월부터

관리자 화면에서 통계를 보고 publication 관리 흐름을 시작합니다.

  • Cloudflare 분석 연동
  • 관리자 로그인과 권한 설정
  • publication 변경은 GitHub PR로 검토

세부 행동 분석

₩0 / 월

GA4로 PDF, GitHub, Project 링크 클릭까지 분석합니다.

  • 맞춤 클릭 이벤트
  • 동의와 개인정보 안내 검토
  • 분석 설정과 유지 관리 증가
구축 비용 안내: 위 금액은 외부 서비스의 월 비용입니다. 로그인, GitHub PR 생성, 통계 화면 구성은 개발 범위이므로 별도 견적이 필요합니다. Cloudflare Workers 무료 플랜은 하루 100,000회 요청까지 제공되며, 이를 초과하거나 유료 기능이 필요하면 월 $5부터 시작합니다. AAIG의 일반적인 관리자 조회 규모에서는 무료 한도 안에서 운영될 가능성이 높습니다.

결론

AAIG에는 Cloudflare Web Analytics로 시작하는 구성이 가장 적합합니다. 비용과 개인정보 부담을 낮추면서 운영에 필요한 통계를 확보하고, 관리자 페이지와 publication 관리 기능은 실제 운영 필요에 맞춰 단계적으로 추가할 수 있습니다.
